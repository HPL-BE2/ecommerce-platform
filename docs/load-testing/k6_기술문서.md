## 1. k6란?

### 1.1 개요

**k6**는 Grafana Labs에서 개발한 오픈소스 부하 테스트 도구입니다.

**핵심 특징:**
- ✅ **고성능**: Go 언어로 작성되어 단일 머신에서 수만 명의 가상 사용자(VU) 생성 가능
- ✅ **개발자 친화적**: JavaScript(ES6)로 테스트 스크립트 작성
- ✅ **CLI 기반**: 자동화 및 CI/CD 통합 용이
- ✅ **풍부한 메트릭**: 실시간 성능 지표 제공
- ✅ **확장성**: 클라우드 연동 가능 (Grafana Cloud k6)

### 1.2 다른 도구와의 비교

| 항목 | k6 | JMeter | Gatling | Locust |
|------|-----|--------|---------|--------|
| **언어** | JavaScript | Java | Scala | Python |
| **GUI** | ❌ | ✅ | ❌ | ✅ (Web UI) |
| **성능** | ⭐⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| **학습 곡선** | 낮음 | 중간 | 높음 | 낮음 |
| **CI/CD** | ⭐⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 3. 기본 개념

### 3.1 Virtual Users (VUs)

**가상 사용자**는 k6가 시뮬레이션하는 동시 실행 스레드입니다.

```javascript
export const options = {
  vus: 10,        // 10명의 가상 사용자
  duration: '30s' // 30초 동안 실행
};
```

### 3.2 Iterations

각 VU가 `default` 함수를 실행하는 횟수입니다.

```javascript
export default function() {
  // 이 함수가 1회 실행 = 1 iteration
  http.get('https://example.com');
}
```

### 3.3 Stages

부하를 단계적으로 증가/감소시키는 설정입니다.

```javascript
export const options = {
  stages: [
    { duration: '2m', target: 100 },  // 2분에 걸쳐 100 VU로 증가
    { duration: '5m', target: 100 },  // 5분 동안 100 VU 유지
    { duration: '2m', target: 0 },    // 2분에 걸쳐 0 VU로 감소
  ]
};
```

### 3.4 Thresholds

성공 기준을 정의하는 SLA입니다.

```javascript
export const options = {
  thresholds: {
    http_req_duration: ['p(95)<500'],  // 95%의 요청이 500ms 이하
    http_req_failed: ['rate<0.01'],    // 에러율 1% 이하
  }
};
```

## 4. 스크립트 작성

### 4.1 기본 구조

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';

// 1. 옵션 정의
export const options = {
  vus: 10,
  duration: '30s',
};

// 2. Setup (전체 테스트 시작 전 1회 실행)
export function setup() {
  // 테스트 데이터 준비
  return { testData: 'value' };
}

// 3. 기본 테스트 함수 (각 VU가 반복 실행)
export default function(data) {
  const res = http.get('https://example.com');

  check(res, {
    'status is 200': (r) => r.status === 200,
  });

  sleep(1);
}

// 4. Teardown (전체 테스트 종료 후 1회 실행)
export function teardown(data) {
  // 정리 작업
}
```

### 4.2 HTTP 요청

#### GET 요청

```javascript
import http from 'k6/http';

export default function() {
  const res = http.get('http://localhost:8080/api/v1/products');
  console.log(res.status); // 200
}
```

#### POST 요청

```javascript
import http from 'k6/http';

export default function() {
  const payload = JSON.stringify({
    userId: 1,
    items: [{ productId: 1, qty: 1 }],
    expectedTotal: 50000
  });

  const params = {
    headers: {
      'Content-Type': 'application/json',
      'Idempotency-Key': `test-${Date.now()}-${__VU}`
    }
  };

  const res = http.post(
    'http://localhost:8080/api/v1/orders',
    payload,
    params
  );

  console.log(res.status); // 201
}
```

### 4.3 체크 (Assertions)

```javascript
import { check } from 'k6';

export default function() {
  const res = http.get('http://localhost:8080/api/v1/products');

  const checkResult = check(res, {
    'status is 200': (r) => r.status === 200,
    'response time < 500ms': (r) => r.timings.duration < 500,
    'body contains data': (r) => r.body.includes('data'),
  });

  if (!checkResult) {
    console.error('Check failed!');
  }
}
```

### 4.4 커스텀 메트릭

```javascript
import { Counter, Rate, Trend, Gauge } from 'k6/metrics';

const errorRate = new Rate('errors');
const orderCount = new Counter('orders_created');
const orderDuration = new Trend('order_duration');

export default function() {
  const start = Date.now();
  const res = http.post('http://localhost:8080/api/v1/orders', payload);
  const duration = Date.now() - start;

  const success = res.status === 201;
  errorRate.add(!success);

  if (success) {
    orderCount.add(1);
    orderDuration.add(duration);
  }
}
```

## 5. 실행 옵션

### 5.1 CLI 실행

#### 기본 실행

```bash
k6 run script.js
```

#### VU 및 Duration 지정

```bash
k6 run --vus 100 --duration 30s script.js
```

#### 환경 변수 전달

```bash
k6 run -e BASE_URL=http://localhost:8080 script.js
```

스크립트에서 사용:
```javascript
const BASE_URL = __ENV.BASE_URL || 'http://localhost:8080';
```

#### Stage 실행

```bash
k6 run --stage 2m:100,5m:100,2m:0 script.js
```

### 5.2 결과 출력 포맷

#### JSON 출력

```bash
k6 run --out json=results.json script.js
```

#### CSV 출력

```bash
k6 run --out csv=results.csv script.js
```

#### InfluxDB로 전송

```bash
k6 run --out influxdb=http://localhost:8086/k6 script.js
```

docker run --rm -i \
  --network="host" \

## 6. 메트릭 및 결과 분석

### 6.1 기본 메트릭

k6는 자동으로 다음 메트릭을 수집합니다:

| 메트릭 | 설명 | 단위 |
|--------|------|------|
| `http_reqs` | 총 HTTP 요청 수 | count |
| `http_req_duration` | 요청 소요 시간 | ms |
| `http_req_blocked` | TCP 연결 대기 시간 | ms |
| `http_req_connecting` | TCP 연결 수립 시간 | ms |
| `http_req_sending` | 데이터 전송 시간 | ms |
| `http_req_waiting` | 서버 응답 대기 시간 (TTFB) | ms |
| `http_req_receiving` | 응답 수신 시간 | ms |
| `http_req_failed` | 실패한 요청 비율 | % |
| `vus` | 활성 가상 사용자 수 | count |
| `vus_max` | 최대 가상 사용자 수 | count |
| `iterations` | 완료된 iteration 수 | count |

### 6.3 Percentile 해석

- **P50 (Median)**: 50%의 요청이 이 값 이하
- **P90**: 90%의 요청이 이 값 이하
- **P95**: 95%의 요청이 이 값 이하 (일반적인 SLA 기준)
- **P99**: 99%의 요청이 이 값 이하

## 7. 고급 기능

### 7.1 시나리오 기반 테스트

```javascript
export const options = {
  scenarios: {
    // 시나리오 1: 상품 조회 (읽기 위주)
    product_browsing: {
      executor: 'constant-vus',
      vus: 50,
      duration: '5m',
      exec: 'browseProducts',
    },

    // 시나리오 2: 주문 생성 (쓰기 위주)
    order_creation: {
      executor: 'ramping-vus',
      startVUs: 0,
      stages: [
        { duration: '2m', target: 20 },
        { duration: '3m', target: 20 },
        { duration: '1m', target: 0 },
      ],
      exec: 'createOrder',
    },
  },
};

export function browseProducts() {
  http.get(`${BASE_URL}/api/v1/products`);
  sleep(1);
}

export function createOrder() {
  http.post(`${BASE_URL}/api/v1/orders`, payload);
  sleep(2);
}
```

### 7.2 데이터 파라미터화

#### SharedArray 사용 (메모리 효율적)

```javascript
import { SharedArray } from 'k6/data';
import papaparse from 'https://jslib.k6.io/papaparse/5.1.1/index.js';

const csvData = new SharedArray('users', function () {
  return papaparse.parse(open('./users.csv'), { header: true }).data;
});

export default function() {
  const user = csvData[Math.floor(Math.random() * csvData.length)];
  http.post(`${BASE_URL}/login`, JSON.stringify({
    username: user.username,
    password: user.password
  }));
}
```

### 7.3 그룹 및 태그

```javascript
import { group } from 'k6';

export default function() {

    group('2. View Product Detail', function() {

      http.post(`${BASE_URL}/api/v1/orders`, payload, {
        tags: { name: 'OrderCreate' }

```

### 7.4 쿠키 및 세션 관리

```javascript
import http from 'k6/http';
import { check } from 'k6';

export default function() {
  // 1. 로그인
  const loginRes = http.post(`${BASE_URL}/login`, {
    username: 'user@example.com',
    password: 'password'
  });

  // 2. 쿠키 자동 관리 (jar 활용)
  const jar = http.cookieJar();
  const cookies = jar.cookiesForURL(loginRes.url);

  // 3. 인증된 요청
  const res = http.get(`${BASE_URL}/api/v1/orders`, {
    cookies: cookies
  });
}
```

## 8. Best Practices

### 8.1 스크립트 작성 팁

✅ **DO:**
- 환경 변수로 BASE_URL 관리
- SharedArray로 테스트 데이터 공유
- 각 VU마다 고유한 Idempotency-Key 생성
- check()로 응답 검증
- sleep()으로 Think Time 시뮬레이션

❌ **DON'T:**
- `console.log()` 과도하게 사용 (성능 저하)
- 테스트 중 파일 쓰기 (I/O 병목)
- 글로벌 변수에 상태 저장 (VU 간 공유 안됨)

### 8.2 성능 최적화

```javascript
// ❌ Bad: 매번 JSON.stringify 호출
export default function() {
  const payload = JSON.stringify({ userId: 1 });
  http.post(url, payload);
}

// ✅ Good: 한 번만 생성
const payload = JSON.stringify({ userId: 1 });
export default function() {
  http.post(url, payload);
}
```

### 8.3 Threshold 설정 권장사항

```javascript
export const options = {
  thresholds: {
    // 응답 시간
    'http_req_duration': ['p(95)<500', 'p(99)<1000'],

    // 에러율
    'http_req_failed': ['rate<0.01'],

    // 특정 API만
    'http_req_duration{name:OrderCreate}': ['p(95)<1000'],

    // Check 성공률
    'checks': ['rate>0.99'],
  }
};
```

## 9. 트러블슈팅

### 9.1 일반적인 에러

#### 에러: `ERRO[0001] GoError: context deadline exceeded`

**원인**: 요청 타임아웃

**해결**:
```javascript
export const options = {
  httpDebug: 'full', // 디버그 활성화
};

// 또는 타임아웃 증가
const res = http.get(url, {
  timeout: '60s'
});
```

#### 에러: `connection refused`

**원인**: 서버가 실행 중이 아니거나 포트 불일치

**해결**:
```bash
# 서버 확인
curl http://localhost:8080/actuator/health

# Docker 네트워크 확인
docker network inspect bridge
```

#### 에러: `too many open files`

**원인**: OS 파일 디스크립터 제한

**해결**:
```bash
# macOS/Linux
ulimit -n 65535

# 영구 설정 (/etc/security/limits.conf)
* soft nofile 65535
* hard nofile 65535
```

### 9.2 디버깅 팁

#### HTTP 요청/응답 출력

```javascript
export const options = {
  httpDebug: 'full',
};
```

#### 특정 반복만 로그 출력

```javascript
export default function() {
  if (__ITER === 0) {
    console.log(`VU ${__VU} first iteration`);
  }
}
```

#### 실패한 요청만 로그

```javascript
const res = http.get(url);
if (res.status !== 200) {
  console.error(`Failed: ${res.status} - ${res.body}`);
}
```

## 부록: 예제 스크립트

### A. 간단한 Smoke Test

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  vus: 1,
  duration: '1m',
};

export default function() {
  const res = http.get('http://localhost:8080/actuator/health');
  check(res, {
    'status is 200': (r) => r.status === 200,
  });
  sleep(1);
}
```

### B. 실전 예제 (주문 생성)

```javascript
import http from 'k6/http';
import { check, sleep } from 'k6';
import { Rate } from 'k6/metrics';

const BASE_URL = __ENV.BASE_URL || 'http://localhost:8080';
const errorRate = new Rate('errors');

export const options = {
  stages: [
    { duration: '2m', target: 100 },
    { duration: '5m', target: 100 },
    { duration: '2m', target: 0 },
  ],
  thresholds: {
    'http_req_duration': ['p(95)<1000'],
    'errors': ['rate<0.01'],
  },
};

export default function() {
  const userId = Math.floor(Math.random() * 100) + 1;
  const productId = Math.floor(Math.random() * 10) + 1;
  const idempotencyKey = `load-test-${Date.now()}-${__VU}-${__ITER}`;

  const payload = JSON.stringify({
    userId: userId,
    items: [
      { productId: productId, qty: 1 }
    ],
    expectedTotal: 50000,
  });

  const params = {
    headers: {
      'Content-Type': 'application/json',
      'Idempotency-Key': idempotencyKey,
    },
  };

  const res = http.post(
    `${BASE_URL}/api/v1/orders`,
    payload,
    params
  );

  const success = check(res, {
    'status is 201': (r) => r.status === 201,
    'has orderId': (r) => JSON.parse(r.body).data.orderId !== undefined,
    'response time < 1s': (r) => r.timings.duration < 1000,
  });

  errorRate.add(!success);

  if (!success) {
    console.error(`Order creation failed: ${res.status} - ${res.body}`);
  }

  sleep(Math.random() * 2 + 1); // 1~3초 랜덤 대기
}
```
